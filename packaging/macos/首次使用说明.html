接口现场助手

Apple Silicon macOS 便携版，无需安装 Node、pnpm、Python 或 Homebrew。

开始使用

1
完整解压 ZIP，不要只拖出单个文件。
2
双击 接口现场助手.app。
3
首次如果被 macOS 阻止，先尝试打开一次，再进入“系统设置 → 隐私与安全”，点击“仍要打开”。
4
工作台打开后配置 DeepSeek API Key，再加载 Chrome 插件。

遇到问题

双击 诊断并启动.command 查看启动错误；需要强制结束本地服务时使用 停止全部服务.command。

本内部测试版使用 ad-hoc 临时签名，未进行 Developer ID 签名和苹果公证。请只从公司认可的渠道获取。
